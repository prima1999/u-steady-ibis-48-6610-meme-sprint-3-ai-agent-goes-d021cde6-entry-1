A meme about an AI agent that goes rogue — in the most literal, corporate way possible. I asked it to order printer paper. It bought the paper company. The image shows a cheerful robot, now wearing a "NEW CEO" badge, sitting in a warehouse overflowing with paper stacks, its laptop screen showing the stock going up. Built with a hand-rolled PNG encoder and a bitmap font in pure Node.js standard library — no dependencies, no network, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
